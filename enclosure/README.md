# 3D-Gehäuse / MakerWorld

Für die Keller Sensorzentrale existiert bereits ein vom Projektinhaber entworfenes Gehäuse. **Die 3MF-/STL-Dateien wurden noch nicht zur Repository-Erstellung bereitgestellt.** Fotos und CAD-Ansichten des fertigen Prototyps sind jetzt in der [Projektgalerie](../docs/galerie/README.md) vorhanden. Wir fügen hier bewusst keine erfundenen Modelle, Maße oder Druckprofile hinzu.

## Hier später ablegen

```text
enclosure/
├── README.md
├── MAKERWORLD-TEXT.md
├── models/       ← 3MF, STL, STEP (wenn vorhanden)
├── photos/       ← Gehäusefotos / Explosionsansicht
└── profiles/     ← Slicer-Profil, optional
```

Zur fertigen Dokumentation werden benötigt: finaler 3MF/STL-Stand, Innenmaße / Platinenaufnahme, Verschraubung, Kabelführungen, USB-Zugang, Material- und Druckeinstellungen, Fotos und gewünschte Nutzungs-/Remix-Lizenz.

## Verknüpfung

Nach der Veröffentlichung hier einen direkten **MakerWorld-Modell-Link** ergänzen und in der GitHub-README verlinken. Umgekehrt in der MakerWorld-Beschreibung auf die Bauanleitung und Firmware auf GitHub verweisen. Keine unbestätigte MakerWorld-URL eintragen.

Das Gehäuse allein stellt keine elektrische Sicherheit, Flammschutz-Zulassung oder Eignung für Heizöltanks bzw. Ex-Zonen sicher.
