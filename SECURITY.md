# Sicherheitshinweise / Security

Bitte **keine Sicherheitslücken mit persönlichen Daten oder Zugangsdaten als öffentliche Issues** posten. Wenn keine private Kontaktmöglichkeit im Repository angegeben ist, zunächst den Maintainer über GitHub kontaktieren und nur eine allgemeine Beschreibung senden.

Diese Firmware betreibt einen ESP8266 im Heimnetz. HTTP und MQTT können abhängig von der Installation unverschlüsselt sein. Keine Router-Portfreigabe oder öffentlich erreichbare Websteuerung einrichten.

Das Projekt ist ein **nicht zertifizierter Niederspannungsprototyp**. Ein Relaisboard darf nicht als Sicherheitsabschaltung verwendet werden. Sensoren und sonstige Elektronik dürfen nicht ohne passende Zulassung in Gefahrenbereichen oder einem Heizöltank installiert werden. Im Zweifel qualifiziertes Fachpersonal und Herstellerangaben hinzuziehen.
